## Clock project
I am very happy that a number of people are interested to design a box for this clock. We can then select the best one (or two or three) and build them. Have fun! 

## Requirements
- Please keep in mind, the box will be 3D printed
- If you would like to add a pattern, colors or picture at the enclosure, it is possible. We may use multicolor 3D printing for one of the projects.
- The panel between segments needs to have black color (otherwise the light from the segments will go through)

## Clock description
The clock is built from addresable RGB leds, so it is possible to change colors of each segment. The clock display is built from four seven segment numbers + two dots in the middle + one dot at the bottom end of display. Additional external addresable RGB LEDs can be connected if it would make the box nicer. There is also a sensor for brigthness at the front and 3 buttons at the back. The clock is powered through USB-C and it has a battery backed up RTC chip which will keep running when USB-C is disconnected (means when USB-C is disconnected, the clock display will show nothing, but when connected again to power, the time will be correct).
